# 约克销售30天打卡激励系统

> 自动化打卡统计 + 排行榜 + 申诉处理，30 天无需人工统计分数。

## 系统特点

- ✅ 完全自动化评分（按你的规则实时计算）
- ✅ 必做联动：早目标未完成 → 晚总结不计分
- ✅ 6 类选做按次累计 + 每类单独封顶 + 当日总分封顶 6
- ✅ 照片客户端实时加水印（姓名 + 时间戳，防 P 图）
- ✅ 自动榜单图生成（一键复制到微信群）
- ✅ 申诉 24h 限时处理
- ✅ 30 天数据全保留，活动结束后可导出

## 让销售在手机上打卡

服务启动后，手机需要能访问到电脑。有 3 种方案：

### 方案 A：同 WiFi 局域网（最简单）
> 本机局域网 IP 是 `192.168.0.8`（如更换网络会变，用 `ipconfig` 查 `IPv4`）。

1. **先放行防火墙**（关键一步，否则手机会被挡）：右键 `open-port-5000.bat` → **以管理员身份运行**，弹出 UAC 点「是」，看到 `[OK] Port 5000` 即可。
2. 销售手机连**同一个 WiFi**（和电脑同一路由器）。
3. 销售手机**用系统浏览器**（Safari / Chrome）打开：`http://192.168.0.8:5000`
4. ⚠️ 不要用微信内置浏览器打开这个 HTTP 链接（会被拦截）；如必须微信内打开，改用方案 B 的 HTTPS 链接。
5. ⚠️ 公司网络若分了多个网段/访客 WiFi，手机可能不在同一网段，此时改用方案 B。

### 方案 B：内网穿透（推荐，适合跨网段 / 微信内打开）
用 **Cloudflare Tunnel**（免费、稳定、不限流量，生成 HTTPS 公网链接，微信也能直接打开）。
本项目已内置 `cloudflared.exe`，无需自己下载：

1. 先按「快速启动」把服务跑起来（双击 `启动.bat`）。
2. 双击 `start-tunnel.bat`，窗口里会出现一个 `https://xxxx.trycloudflare.com` 的链接。
3. 把这个链接发给销售，手机（任何网络、微信内）都能直接打开打卡。

⚠️ 该窗口需保持打开；链接每次重启隧道会变（免费版特性）。如需固定链接，见方案 C。

### 方案 C：直接部署到云
如需长期 24/7 不间断运行，建议部署到云服务器（阿里云、腾讯云等）。
本项目是标准 Flask 应用，部署简单。

## 使用流程

### 群主/管理员
1. 打开 http://localhost:5000
2. 输入姓名 + 微信号 + **邀请码 `yorke2026`**

   - 查看任一成员打卡明细（点姓名）

1. 浏览器打开链接（同 WiFi 或内网穿透 URL）
2. 输入**姓名 + 微信号**登录
3. 点击对应打卡项 → 填内容 + 上传照片（自动加水印）→ 提交
4. 可看「我的进度」和「榜单」

## 常见问题

**Q: 销售点开链接白屏？**
A: 让他们用浏览器（不要用微信内置浏览器打开 HTTP 链接，会被拦截）。如果必须微信内打开，用 HTTPS 链接（方案 B/C）。

**Q: 销售反馈打卡失败？**
A: 检查是不是过了 9:30 / 20:00 截止时间。必做项有截止时间校验。

**Q: 我想加新规则怎么办？**
A: 修改 `app.py` 顶部的 `OPTIONAL_CAPS` 等配置即可。

**Q: 数据库会丢吗？**
A: 不会。SQLite 落盘到本地 `data/checkin.db`，只要不删这个文件就一直在。建议每周备份一次。
